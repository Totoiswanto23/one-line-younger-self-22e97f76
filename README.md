The one line the writer would send back to their younger self if a single line were all they got: no explanation, no context, no second sentence.

## The entry

> Put the phone down — the kid asleep on your chest doesn't care about your bank balance, and he's only this small once.

118 characters, one line, in second person. It is addressed to the younger self directly, and its sting is a real image from a life actually lived: a tired parent on his phone while his kid sleeps on him. The turn lands in the last words — he is only this small once.

## Run it

```sh
node main.ts
```

`main.ts` validates the line (one line, 1–200 characters, not only whitespace) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline so the file is exactly the one line.
